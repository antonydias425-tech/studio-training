# Studio Training - site

Página única em HTML, CSS e JavaScript puros. Não precisa instalar nada.

## Arquivos
- `index.html`: estrutura e textos da página
- `style.css`: visual, cores, fontes e animações
- `script.js`: efeitos (números animados, aparecer ao rolar, cabeçalho)
- `img/`: coloque aqui as fotos reais do estúdio e da Carol

## Antes de publicar
1. Trocar a ilustração do topo e o marcador "Foto da Carol" por fotos reais (procure por `TROCAR` no `index.html`).
2. Completar a linha entre colchetes na seção "Quem cuida do seu treino".
3. Conferir os depoimentos (baseados em avaliações públicas do Google) e pedir autorização.
4. Conferir nota e número de avaliações do Google na faixa de números.

## Publicar grátis no GitHub Pages
1. Suba esta pasta em um repositório no GitHub.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
4. Para usar um domínio próprio (.com.br), crie um arquivo `CNAME` com o domínio e aponte o DNS no Registro.br.
